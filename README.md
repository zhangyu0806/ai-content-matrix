# AI Content Matrix Generator

> 1篇长文自动拆解为10条短内容 - 覆盖小红书、抖音、B站、公众号

## ✨ 核心功能

- 📝 **智能内容拆解**：AI提取核心观点，重新组织为多平台格式
- 🎯 **平台适配**：自动生成小红书、抖音、B站、公众号专用格式
- 🚀 **批量生产**：1周生成100+条高质量内容
- 📊 **SEO优化**：关键词提取、标题优化、标签推荐

## 🎯 适用场景

- 🛒 **电商运营**：产品介绍、用户评价、使用教程
- 📰 **新媒体公司**：每日内容生产、多平台分发
- 🏢 **中小企业**：品牌宣传、产品推广
- 💼 **个人创作者**：知识分享、账号涨粉

## 📦 安装

```bash
# 克隆仓库
git clone https://github.com/zhangyu0806/ai-content-matrix.git
cd ai-content-matrix

# 安装依赖
pip install -r requirements.txt
```

## 🚀 快速开始

### 1. 基础用法

```bash
# 生成内容矩阵
python content_splitter.py input_article.md --platform xiaohongshu,bilibili

# 查看演示
streamlit run demo_app.py
```

### 2. 平台选项

```bash
--platform xiaohongshu    # 小红书（emoji+标签）
--platform douyin          # 抖音（短视频脚本）
--platform bilibili        # B站（长视频文案）
--platform wechat          # 公众号（长文格式）
```

## 📊 功能演示

### 输入：1000字长文

### 输出：10条跨平台内容

**小红书（3条）：**
- 👗 产品种草：emoji丰富，标题吸引
- 💡 使用教程：步骤清晰，带配图建议
- ⚡ 快速 tips：干货满满，易传播

**抖音（3条）：**
- 🎬 15秒脚本：黄金前3秒，强冲突
- 📱 产品展示：多角度，特效建议
- 💬 互动引导：点赞关注话术

**B站（2条）：**
- 📺 5分钟视频：深度解析，干货输出
- 🎓 知识分享：专业度高，适合学习

**公众号（2条）：**
- 📰 长文：深度分析，数据支撑
- 📊 图文：排版美观，适合阅读
