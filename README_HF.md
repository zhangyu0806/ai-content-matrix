# 🚀 AI内容矩阵生成器

> **1篇长文 → 15+条多平台短内容**

## ✨ 核心功能

- 🔍 **智能关键观点提取** - TF-IDF + 位置权重算法
- 🏷️ **SEO关键词优化** - 自动提取高价值关键词
- 📱 **6平台内容适配** - 小红书/抖音/B站/公众号/知乎/微博
- 📝 **标题优化** - 4种风格模板（钩子/数字/教程/对比）
- 📊 **批量处理** - 一次处理多篇文章
- 📅 **内容日历** - 自动生成发布排期
- 💾 **多格式导出** - Markdown/CSV/JSON

## 🎯 使用场景

- 新媒体运营：多平台账号管理
- 电商卖家：产品推广内容批量生成
- 知识博主：专业知识通俗化
- 企业品牌：多渠道统一输出
- 自媒体创业：一人团队高效运营

## 📦 如何使用

1. 粘贴或输入长文内容（建议500字以上）
2. 选择目标平台（支持多选）
3. 可选：输入关键词（留空则自动提取）
4. 点击"生成内容矩阵"按钮
5. 查看结果并下载
