# 如何用Python实现「1篇文章→15条多平台内容」的自动化？

做新媒体运营的朋友应该都有这个痛点：写完一篇深度文章后，还要手动改成小红书笔记、抖音脚本、B站视频大纲、知乎回答……每个平台的风格、格式、字数要求都不一样，改一遍下来比重新写还累。

我用Python做了个工具来解决这个问题，分享一下思路和实现。

## 核心思路

**1篇长文 → N个关键观点 → N×6平台内容**

关键在两步：
1. 从长文中自动提取核心观点
2. 根据不同平台的风格规则，自动适配内容格式

## 技术实现

### 关键词提取

没有用外部API，自己实现了一个轻量版TF-IDF：

- 中文分词：正则切分 + 2-6字组合
- 词频统计 + 位置加权（前20%的词权重×1.5）
- 停用词过滤
- 输出Top 8关键词

### 观点提取

启发式规则：
- 含关键词的句子优先
- 含数字的句子加分（通常是数据/案例）
- 20-80字的句子信息密度最高
- 段落首句通常是主题句
- 去重（相似度>0.5的合并）

### 平台适配

每个平台一套模板规则：

| 平台 | 标题风格 | 正文特点 | 输出条数 |
|------|---------|---------|---------|
| 小红书 | emoji+情绪化 | 短段落+标签 | 4条 |
| 抖音 | 悬念+数字 | 口语化脚本 | 3条 |
| B站 | 【教程】指南 | 结构化讲解 | 2条 |
| 公众号 | 深度标题 | 完整叙事 | 1条 |
| 知乎 | 问答式 | 专业分析 | 2条 |
| 微博 | 短平快 | 热点结合 | 3-4条 |

## 实际效果

测试了几种类型的文章：
- 技术博客（1500字）→ 生成19条内容
- 产品评测（2000字）→ 生成17条内容
- 行业分析（1800字）→ 生成18条内容

质量大概70-80分，核心观点提取准确率还不错，平台适配的格式基本到位。需要人工微调的主要是标题和一些细节表述。

## 局限性

说实话，纯规则引擎的天花板在那里：
- 不理解语义，只能做模式匹配
- 生成的内容有模板感
- 复杂文章的观点提取可能不够精准

如果接入LLM（比如GPT-4/Claude），质量可以再上一个台阶。但纯本地方案的好处是零成本、零延迟、数据不出本地。
