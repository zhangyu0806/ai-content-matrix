# HF Space 部署 - 立即行动指南

## 子宇，这是你需要做的事（5分钟搞定）

### 方案A：HuggingFace Space（推荐，免费）

**第1步：登录HF**
1. 打开：https://huggingface.co
2. 登录你的账号

**第2步：创建Space**
1. 点击右上角 "+" → "New Space"
2. 填写：
   - Space name: `seo-content-matrix`
   - License: MIT
   - SDK: Streamlit
   - Hardware: CPU basic（免费）

**第3步：上传文件**
使用Git上传（在项目目录执行）：

```bash
cd /root/.openclaw/workspace/gtd/010-Project/active/SEO内容矩阵

# 添加远程仓库（替换YOUR_USERNAME为你的HF用户名）
git remote add hf https://huggingface.co/spaces/YOUR_USERNAME/seo-content-matrix

# 如果已存在，先删除
git remote remove hf
git remote add hf https://huggingface.co/spaces/YOUR_USERNAME/seo-content-matrix

# 推送
git push hf main
```

**需要的文件清单**：
- `app_streamlit.py` ✅
- `content_splitter.py` ✅
- `README_HF.md` → 需重命名为 `README.md`
- `requirements.txt` ✅

**第4步：等待构建**
- HF会自动构建（2-5分钟）
- 完成后你会得到公开URL：`https://huggingface.co/spaces/YOUR_USERNAME/seo-content-matrix`

**第5步：测试**
- 访问你的Space URL
- 粘贴测试文本
- 点击生成

### 方案B：云服务器部署（备选，需要子宇操作）

如果HF Space有问题，可以部署到现有云服务器：

```bash
cd /root/.openclaw/workspace/gtd/010-Project/active/SEO内容矩阵

# 启动服务
nohup python3 -m streamlit run app_streamlit.py --server.port=8501 --server.address=0.0.0.0 > streamlit.log 2>&1 &

# 服务会在 http://38.55.133.19:8501 运行
```

**然后配置nginx反向代理**（如果需要）：

```nginx
streamlit {
    listen 80;
    server_name your-domain.com;

    location / {
        proxy_pass http://127.0.0.1:8501;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```
