# [分享] 做了个AI内容矩阵工具，1篇长文自动拆成15条短内容

周末花了点时间做了个小工具，解决自己做自媒体时的一个痛点：每次写完一篇长文，还要手动改成小红书、抖音、B站等不同平台的格式，太费时间了。

## 工具做了什么

输入一篇长文（比如技术博客、产品评测），自动：

1. 提取核心关键词（TF-IDF + 位置权重）
2. 识别8-10个关键观点
3. 生成6个平台的适配内容：
   - 小红书：emoji风格图文笔记
   - 抖音：短视频脚本（黄金3秒开头）
   - B站：知识视频大纲
   - 公众号：深度长文
   - 知乎：专业回答
   - 微博：短平快正文

## 在线Demo

👉 https://zhangyu0806.github.io/ai-content-matrix/

纯前端，不需要登录，粘贴文章直接生成。

## 技术实现

- 纯Python，核心逻辑500行
- 关键词提取：自己实现的TF-IDF（不依赖外部API）
- 平台适配：模板引擎 + 风格规则
- 前端：纯HTML/JS，无框架依赖
- 后端：Flask API + Streamlit界面（可选）

GitHub: https://github.com/zhangyu0806/ai-content-matrix

## 实际效果

测试了几篇文章，平均每篇能生成15-19条内容。质量大概能到70-80分，需要人工微调20%左右。但比从零写快太多了。

## 适用场景

- 新媒体运营：批量生成多平台内容
- 个人IP：一个人运营多个平台
- 电商：商品评测→种草内容
- 教育：课程内容→推广素材
